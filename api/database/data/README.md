# Indonesia administrative regions data

`indonesia_regions.json` contains the 38 provinces and 514 regencies/cities
using BPS codes, derived from the 2025 Semester 1 data in
[kode-wilayah-id](https://github.com/sumitroajiprabowo/kode-wilayah-id).
Province and regency names are formatted for display; each regency/city points
to its province using `parent_id`.
